# Dino Run — DIO GameDev

Releitura moderna do clássico jogo do dinossauro, desenvolvida por **Anthony Freitas** a partir do desafio "Recriando o famoso jogo do dinossauro sem internet" da DIO.

https://sammyfreitas.github.io/DIO_GameDev_Dino/


## Melhorias desta versão

- Interface totalmente redesenhada e responsiva
- Tema claro e escuro com preferência salva no navegador
- Modo **Desafio** de 60 segundos e **Modo Livre**
- 3 vidas e contador de erros/colisões
- Pontuação dinâmica por sobrevivência e obstáculos superados, com penalidade por erro
- Dificuldade e velocidade progressivas
- Recorde salvo com `localStorage`
- Pausa, reinício e opção de jogar novamente
- Controles por teclado e toque para dispositivos móveis
- Links para redes sociais e portfólio
- Versão original preservada em `old/`

## Controles

- `Espaço` ou `↑`: saltar
- `P`: pausar/continuar
- Celular/tablet: toque na pista para saltar

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome
